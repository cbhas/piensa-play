# Misión: Ciberseguridad 🔐

## Descripción
Esta misión enseña a los niños sobre seguridad en internet, contraseñas seguras, y cómo protegerse de amenazas en línea.

## Estructura de Archivos

### Páginas (presentation/pages/ciberseguridad/)
Crea las siguientes páginas para tu misión:
- `ciberseguridad_intro_page.dart` - Página de introducción
- `ciberseguridad_question_page.dart` - Página de preguntas
- `ciberseguridad_feedback_page.dart` - Página de retroalimentación
- Puedes reutilizar `quiz_results_page.dart` de veracidadville

### Datos (data/datasources/ciberseguridad/)
- `ciberseguridad_quiz_data.dart` - Datos de las preguntas del quiz

### Entidades (domain/entities/ciberseguridad/)
- Define tus propias entidades según el tipo de quiz que quieras crear

## Temas Sugeridos
1. **Contraseñas Seguras**: Enseñar a crear contraseñas fuertes
2. **Phishing**: Identificar correos y mensajes sospechosos
3. **Privacidad en Redes Sociales**: Qué compartir y qué no
4. **Descargas Seguras**: Identificar sitios web seguros

## Colores Sugeridos
- Color principal: `Color(0xFFFF6B6B)` (Rojo/Naranja)
- Color secundario: `Color(0xFFFFD93D)` (Amarillo)
- Emoji principal: 🔐 o 🛡️

## Ejemplo de Estructura
Puedes basarte en la estructura de Veracidadville pero adaptarla a tu tema.

## Notas
- Mantén el diseño colorido y animado para niños
- Usa emojis relevantes al tema de seguridad
- Asegúrate de que las explicaciones sean claras y educativas
